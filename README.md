# CiFrA — лендинг «Цифровая защита»

Суверенный ИИ в закрытом контуре под ключ: локальные LLM, RAG и компьютерное зрение на серверах заказчика без выхода в интернет.

Сайт: https://smit1980.github.io/CiFrA/

Статичная страница без сборки на стороне хостинга: HTML, стили Tailwind (уже собраны в `assets/css/styles.css`), анимация частиц на canvas (`assets/js/field.js`).

Иконки — [Solar Icons](https://www.figma.com/community/file/1166831539721848736) от 480 Design, лицензия CC BY 4.0. Шрифты Unbounded и Onest — Google Fonts, лицензия OFL.
